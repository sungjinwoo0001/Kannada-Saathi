# ಕನ್ನಡ ಸಾಥಿ | Kannada Saathi

### Learn Kannada Through Real-Life Conversations

Kannada Saathi is an interactive Kannada learning platform designed to help beginners communicate confidently in everyday situations in Karnataka.

## Problem Statement
**Kannada in Everyday Life**

## Problem
People who are new to Karnataka often face language barriers when travelling, shopping and asking for directions.

## Solution
Kannada Saathi makes learning Kannada easier through practical, interactive missions that simulate everyday conversations.

## Features

- 🚌 **Bus Mission:** Learn Kannada for public transportation.
- 🛍️ **Shopping Mission:** Practise conversations at local shops.
- 🧭 **Directions Mission:** Learn how to ask for and understand directions.
- 🔊 **Audio Pronunciation:** Listen to Kannada phrases using text-to-speech.
- 📖 **English Meaning:** Understand the meaning of Kannada phrases.
- 🎯 **Interactive Learning:** Answer questions, retry incorrect answers and earn scores.

## Technology Stack

- Python
- Gradio
- Microsoft Edge Text-to-Speech (Edge TTS)

## Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project directory:

   ```bash
   cd kannada-saathi
   ```

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:

   ```bash
   python app.py
   ```

**Note:** An internet connection is required for Edge TTS audio generation.
